# Research rigor and open-source licensing policy

Research results include retrieved URL/registry, publication or version date, access date, source authority, stated fact, confidence and unresolved limitations. Prefer current official docs and primary sources; verify code examples against supported versions. Package popularity is neither security nor maintenance assurance.

Before adoption record license and compatibility with project distribution, dependency advisories, maintainer activity, transitive tree, update route, integration and replacement cost. For unclear licenses or legal obligations, escalate for appropriate professional review; agents must not render legal certainty. Cite benchmark methodology rather than repeating unsourced performance comparisons.
