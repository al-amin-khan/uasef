# Project knowledge and continuity policy

Canonical knowledge is versioned PRDs/SRS, specifications, accepted ADRs, source code, CI results and approved workflow state. Retrieval indexes and agent conversations are derived convenience layers, never independent authority. Every decision has status, owner, source, date, alternatives and links. Supersede previous ADRs instead of rewriting history.

Before any agent begins work, build a narrow context bundle from task and dependencies, current requirement IDs, latest accepted ADRs, actual branch+commit, touched code, CI evidence, open issues. On handoff list completed work, remaining, tested/not tested, blockers and next verifiable action. Successor independently checks actual state; private internal reasoning cannot be transferred.

Do not dump entire transcripts as memory. Redact secrets, unnecessary personal data and raw credentials from handoffs.
