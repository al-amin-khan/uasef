# Handoff contract

A successor agent needs: project version, task ID, approved requirement references, ADR references, current branch and verified commit, touched files, actual tested commands/outcomes, current blockers, dependencies, specific next safe action, security-sensitive assumptions and relevant evidence paths.

Use structured fact status: VERIFIED / ASSUMED / UNKNOWN / REJECTED. Do not include secrets, personal data, entire chat history, or private chain-of-thought. Successor validates the repository and tool permissions before acting.
