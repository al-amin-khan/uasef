# UI/UX preview files

Store reviewable visual artifacts for each UASEF task here. Use the task ID as a folder.

Example: previews/UX-001/README.md, previews/UX-001/mockups/home-desktop-1440x900.png, and previews/UX-001/screenshots/home-desktop-chrome-windows-1440x900.png.

The UX task folder README records the screen, source/revision, exact viewport or device, browser/OS, mocked content/assets, and owner-review status. Export images from Figma or another remote design tool here as well as recording the source link. Use synthetic/demo content; never include private user information, production data, credentials, or secrets.

Define a project-specific device/browser/OS matrix from intended users and available usage data. Capture the approved mockup and rendered implementation at matching targets. Pixel-perfect status is limited to those named targets that were actually compared; note all remaining differences. This guide does not promise identical rendering on every device.
